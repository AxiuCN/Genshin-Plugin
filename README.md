# Genshin-Plugin / 原神插件

> 提取自 [Miao-Yunzai](https://github.com/yoimiya-kokomi/Miao-Yunzai) 的 `plugins/genshin` 目录，独立维护，定期同步上游更新。

## 简介

本插件为 TRSS-Yunzai v3 提供原神相关功能，包括米游社数据查询、抽卡记录、Cookie 管理、兑换码使用等。通过子树（subtree）方式从主仓库中提取，保留完整提交历史，方便独立跟进。

## 安装

在 Yunzai 根目录下执行：

```bash
git clone --depth=1 https://github.com/AxiuCN/Genshin-Plugin.git ./plugins/genshin/
```

> 如果已有旧版 `genshin` 插件，请先删除或备份。

## 同步上游更新

本仓库通过 `git subtree` 与上游保持同步，你可以在本地合并上游的最新更改，然后推送到本仓库：

```bash
# 添加上游远程（仅首次）
git remote add upstream https://github.com/yoimiya-kokomi/Miao-Yunzai.git

# 拉取上游最新代码
git fetch upstream

# 将上游 master 分支中 plugins/genshin 的更新合并到当前分支
git merge -s recursive -Xsubtree=plugins/genshin upstream/master

# 推送
git push origin master
```

## 功能

### 米游社查询

| 指令 | 说明 |
|------|------|
| `#角色`、`#探险`、`#角色卡片` | 米游社角色数据查询 |
| `#刻晴` | 指定角色详情 |
| `#武器`、`#五星`、`#四星`、`#角色背包` | 角色详情扩展 |
| `#深渊`、`#深渊十二层` | 深渊数据查询 |
| `#刻晴突破`、`#刻晴素材` | 角色突破素材图 |
| `#刻晴攻略` | 西风攻略 |
| `#练度统计`、`#五星列表`、`#天赋列表` | 角色练度统计 |
| `#体力` | 当前体力查询 |
| `#原石`、`#原石七月` | 原石札记 |
| `#原石统计`、`#2022年原石统计`、`#原石任务` | 原石历史统计 |
| `#今日素材` | 按拥有角色查询今日素材 |
| `#公告`、`#公告2`、`#资讯`、`#活动` | 米游社原神公告资讯 |
| `#米游社xxx` | 帖子搜索 |
| `#开启/关闭公告推送`、`#开启/关闭资讯推送` | 公告推送开关 |
| `#原神开启/关闭到期活动预警推送` | 活动截止预警 |
| `#原石预估` | 新版本可获取原石预估 |

### 抽卡模拟

| 指令 | 说明 |
|------|------|
| `#十连` | 角色池模拟十连（每日一次） |
| `#十连武器` | 武器池模拟十连 |
| `#十连常驻` | 常驻池模拟十连 |
| `#定轨` | 武器池定轨 |

### Cookie 管理

| 指令 | 说明 |
|------|------|
| `体力帮助`、`cookie帮助` | Cookie 绑定教程 |
| `cookie代码` | 获取 Cookie 的 JS 代码 |
| `#绑定cookie` | 绑定米游社 Cookie |
| `#删除cookie` | 删除绑定的 Cookie |
| `#绑定uid` | 绑定游戏 UID |
| `#uid` | 显示已绑定 UID |
| `#我的ck` | 当前主 Cookie |
| `#配置ck` | 添加公共查询 CK |
| `#使用用户ck` | 将用户 CK 加入公共 CK 池 |
