祈愿记录统计 · 帮助

推荐自动拉取：无需链接
若已完成【#扫码登录】绑定，可直接使用以下命令自动获取抽卡记录：
#更新抽卡记录　米游社官方 API 增量更新（最近 12 个月，约 5 分钟频率限制）
#更新小助手抽卡记录　提瓦特小助手全历史导入（无需链接，自动换 authkey）
#获取抽卡链接　获取抽卡 URL（需私聊发送，供手动导入备用）
链接导入（备用）
游戏内「祈愿记录」页面复制链接，私聊发送给机器人即可：
#更新小助手抽卡记录 <链接>　带链接导入全历史记录
或直接发送抽卡链接，机器人自动解析。
如何获取链接：无需手动获取——完成 #扫码登录 绑定（Axiu-Plugin stoken 体系）后，用 #更新抽卡记录 自动拉取即可
文件导入
私聊发送 #原神导入记录json 后再发送 xlsx / json 文件，或直接发送抽卡数据文件导入
查询统计命令
#角色记录　#武器记录　#常驻记录　#集录记录　各池祈愿记录
#角色统计　#武器统计　抽卡数据统计（五星平均抽数、角色抽数等）
#导出记录　导出 UIGF 标准记录文件
其他说明
· 数据存在一小时左右延迟，最多可获取最近 12 个月的记录
· 需更新数据时，重新拉取最新记录或重新发送链接即可
· 链接发送失败：删除域名后再发送，或添加机器人为好友
· 链接过长复制不完整：换个输入法即可解决
