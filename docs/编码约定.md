# 编码约定

> ESM、渲染、路径等硬约定，以及插件 class 的注册方式。

1. **ESM** — 全部 `import`/`export`，不使用 `require`
2. **日志标签** — 沿用框架默认，无统一前缀。各模块自行输出 `logger.info/warn/error`
3. **事件注册** — 使用 `rule[]` 注册命令
4. **容错加载** — `index.js` 使用 `Promise.allSettled`，单个 app 失败不影响整体
5. **数据库层** — `model/db/` 封装本地数据存储，`BaseModel.js` 为 Sequelize 初始化入口
6. **米游社 API** — `model/mys/` 封装米游社 HTTP 接口。`mysApi.js` 负责 HTTP + DS 签名，`apiTool.js` 负责 URL 构造，`MysInfo.js` 负责查询编排和错误处理
7. **HTML 渲染** — 通过 `base.renderImg()` → `Common.render()`（miao-plugin 的 puppeteer 渲染），模板位于 `resources/html/`
8. **图片回复** — `this.reply(img)` 或 `await this.renderImg("genshin", tpl, data)`，返回 base64 时传 `{ retType: "base64" }`
9. **路径获取** — 使用 `process.cwd()` 获取 Yunzai 根目录，不硬编码绝对路径
10. **上游同步** — 改动时注意与上游 Miao-Yunzai 的兼容性，避免在同步时产生大量冲突

## 插件 class API 参考

```js
import plugin from '../../../lib/plugins/plugin.js'

class MyFeature extends plugin {
  constructor() {
    super({
      name: "功能名称",
      dsc: "功能描述",
      event: "message",
      priority: 5000,
      rule: [{
        reg: /^#命令/,
        fnc: "methodName",
        permission: "all",
      }],
    })
  }

  // 可选：所有消息先经过此方法，返回 true 表示拦截
  async accept() {
    // 若命中角色别名，修改 this.e.msg 为标准命令
    let role = gsCfg.getRole(this.e.msg)
    if (role) {
      this.e.msg = "#角色详情"
      this.e.roleId = role.roleId
      return true
    }
  }

  async methodName() {
    // this.e 是 Runtime 实例
    // 回复文本：this.e.reply(msg)
    // 回复图片：this.reply(await this.renderImg(...))
    // 回复消息 + 按钮：this.reply([...])
  }
}
```
