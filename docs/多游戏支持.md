# 多游戏支持

> 原神 / 星铁 / 绝区零 三游戏在同一套代码里如何区分。

三种游戏通过以下机制区分：

1. **消息前缀**：`#` 开头为原神，`*` 开头为星铁（框架自动设置 `e.isSr`）
2. **`e.game`**：由各 app 设置，值为 `"gs"` / `"sr"` / `"zzz"`
3. **资源路径**：原神用 `resources/`，星铁用 `resources/StarRail/`，绝区零用 `resources/ZZZero/`
4. **UID 正则**：原神/星铁 `/(18|[1-9])[0-9]{8}/`，绝区零 `/(1[0-9]|[1-9])[0-9]{8}|[1-9][0-9]{7}/`
5. **MysApi server**：通过 UID 前缀判断（`5`=B服、`6`=美服、`7`=欧服、`8`/`18`=亚服、`9`=港澳台）
