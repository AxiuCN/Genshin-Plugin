## 待验证

### 兑换码过期时间：星铁 / 崩三 / 绝区零

**状态**：等某期前瞻活动窗口。兑换码过期后接口返回 `-500007`，只能在有效期内测。

要验的 4 点：

1. `miyolive index` 的 `template.codeTipText` 是否存在，正则解析结果是否与官方口径一致
2. `live.start` / `live.end` 是否权威（用作年份基准与兜底基准）
3. 兜底天数是否与实际相符 —— **重点崩三 / 绝区零**：历史代码两条路径本身不一致（崩三主路 +5 / 备用 +1，绝区零主路 +1 / 备用 +2），现统一为崩三 1 天 23:59、绝区零 2 天 23:59，**未实测**
4. `act_id` 获取路径是否有效 —— **崩三 / 绝区零此前动态列表与导航两条路都未命中**；若平时也拿不到，`#兑换码` 对它们本就是失效状态（既有隐患，不是某次改动引入）

已验证（原神，2026-09 期）：官方文案「兑换码将于9月15日12:00过期」→ 解析 `2026-09-15 12:00:00`；同批次的 `live.end`（2026-09-12 21:16:10）+ 3 天兜底得到同一时刻，互为校验。

### 字段全缺时的「未知」

`getExpireTime()` 三个来源都取不到时输出「未知」并 `logger.warn`，不再给推算值。**是否可接受尚未确认**（另一种选择是继续输出兜底推算值）。
